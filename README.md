# JB-Star OTT

A new OTT/live sports platform foundation.

## Planned modules

- User web app
- Android user app (APK)
- Admin web panel
- Separate admin Android app
- Firebase Authentication and data layer
- Live cricket score integration (authorized data provider)
- Authorized video/live-stream playback
- Search, categories, watchlist
- Free tier with ads and Pro tier without ads
- Subscription/payment integration
- Push notifications

## Authentication

Firebase Authentication will support phone OTP and supported social providers. Firebase configuration files and secrets are intentionally not committed to this repository.

## Development

This repository is being built from scratch and is not based on the previous CricketPlay APK/codebase.
